# Transport Normes Site — Domain Context

Static site generator for French transport data norms (NeTEx FR, SIRI FR). Converts markdown specifications into DSFR-styled HTML with navigation chrome.

## Navigation

**Navigation plugin**: MDEx AST transform that auto-generates heading IDs and extracts a TOC tree from document headings. It only modifies the AST — it does not compute section lists or current-section state; those belong to the build pipeline or layout layer.

_Avoid_: Sections, navigation chrome (those are separate concerns)

**Heading ID**: Deterministic anchor identifier generated by slugifying a heading's plain text content. Unique per document; duplicate headings get numeric suffixes (`-1`, `-2`). Slugs are lowercase, accent-stripped, space-separated with hyphens.

_Avoid_: Random IDs, UUIDs, position-based IDs

**TOC tree**: Nested list of all headings in a page, preserving document hierarchy. Each entry has `id`, `text` (plain text without formatting), and `children`. Stored in MDEx private fields during plugin attach, extracted before `to_html!()`.

**Section**: A top-level (`# H1`) heading within a page. Represents a logical division of content. Scope is per-page; cross-file section indexing is handled by the build pipeline. This definition may need refinement as patterns emerge.

_Avoid_: Directory name (directories map to pages, not sections)

**Slugification**: Process of converting heading text to a URL-safe identifier: extract plain text (stripping all inline formatting), lowercase, strip accents, replace whitespace with hyphens, remove non-alphanumeric characters except hyphens.

## Data Flow

```
Markdown file → MDEx.parse() → Navigation.attach() → FrontMatter.attach() → MDEx.to_html!()
                        │                              └─→ private(:toc_tree) extracted for layout
```
